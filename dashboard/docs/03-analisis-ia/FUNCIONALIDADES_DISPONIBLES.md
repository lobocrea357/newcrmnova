# 🎛️ Funcionalidades Disponibles
## Sistema de Análisis de Ventas con IA

## 🤖 FUNCIONALIDADES AUTOMÁTICAS (Sin intervención)

### **⏰ Análisis Diario Automático**
- ✅ **Se ejecuta todos los días a las 24:00**
- ✅ **Analiza últimas 20 conversaciones** de cada asesor
- ✅ **Filtra automáticamente** chats internos y grupos
- ✅ **Detecta ventas confirmadas** con IA
- ✅ **Identifica leads calientes** automáticamente
- ✅ **Genera reportes profesionales** sin intervención
- ✅ **Almacena todo en base de datos** organizadamente

### **🧠 Análisis Inteligente**
- ✅ **Distingue clientes reales** vs chats internos
- ✅ **Evalúa 8 parámetros comerciales** automáticamente
- ✅ **Extrae valores de venta** de conversaciones
- ✅ **Clasifica nivel de interés** del cliente
- ✅ **Cache inteligente** (no re-analiza conversaciones)

### **📊 Dashboard en Tiempo Real**
- ✅ **Métricas actualizadas** por asesor
- ✅ **Comparativas automáticas** de rendimiento
- ✅ **Alertas de rendimiento crítico** (score < 5)
- ✅ **KPIs globales** del equipo

## 👤 FUNCIONALIDADES MANUALES (Bajo demanda)

### **🎯 Análisis Manual Específico** (`/rendimiento/muestra-analisis`)
- 🔧 **Seleccionar asesor específico** para analizar
- 🔧 **Elegir conversaciones manualmente** 
- 🔧 **Ejecutar análisis inmediato** con IA
- 🔧 **Ver resultados detallados** al instante
- 🔧 **Generar reporte específico** para casos puntuales

### **⚙️ Panel de Administración** (`/admin`)
- 🔧 **Iniciar/Detener** sistema automático
- 🔧 **Configurar horario** de análisis diario
- 🔧 **Cambiar zona horaria** del sistema
- 🔧 **Ajustar número** de conversaciones por asesor
- 🔧 **Trigger análisis manual** de todo el equipo
- 🔧 **Ver logs del sistema** y errores
- 🔧 **Monitorear estado** en tiempo real

### **👥 Gestión Individual** (`/rendimiento/asesor/[id]`)
- 🔧 **Ver historial completo** de un asesor
- 🔧 **Revisar conversaciones evaluadas** específicas  
- 🔧 **Examinar chat completo** con mensajes
- 🔧 **Comparar evolución** temporal
- 🔧 **Acceder a reportes** generados

### **📄 Gestión de Reportes** (`/rendimiento/reportes`)
- 🔧 **Ver todos los reportes** generados
- 🔧 **Filtrar por fecha** y asesor
- 🔧 **Generar reportes faltantes** manualmente
- 🔧 **Descarga de reportes** (cuando esté PDF)
- 🔧 **Regenerar reportes** si es necesario

---

## 💡 **Resumen de Uso**

### **Para Gerentes:**
- **🤖 Automático**: Recibe análisis completos todos los días sin hacer nada
- **👤 Manual**: Control total cuando necesita análisis específicos o inmediatos

### **Para Administradores:**
- **🤖 Automático**: Sistema se gestiona solo, logs automáticos, reportes diarios
- **👤 Manual**: Panel completo para configurar, monitorear y controlar todo

### **Para el Negocio:**
- **🤖 Automático**: Proceso comercial monitoreado 24/7 sin intervención humana
- **👤 Manual**: Análisis específicos para decisiones puntuales o casos especiales

---

## 🎯 **Lo Mejor de Ambos Mundos**

✅ **Automatización**: Todo funciona solo, reportes diarios garantizados
✅ **Control Manual**: Flexibilidad total cuando se necesita
✅ **Sin Bloqueos**: El sistema manual no interfiere con el automático
✅ **Complementarios**: Ambos usan la misma IA y base de datos

**Resultado: 90% automatizado + 10% control manual = 100% efectividad**
